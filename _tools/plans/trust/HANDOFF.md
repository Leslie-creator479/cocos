# 인계서: '믿고 맡길 수 있는 학원' 작업 (2026-11-08)

홈페이지 방(저장소 `Leslie-creator479/cocos`, https://cocosedu.kr)에서 넘기는 작업이다.
'우리 지역 학교를 잘 아는 학원'이라는 인상은 학교별 영어 내신 가이드·고등학교 비교표·수능 관리 칸으로 어느 정도 갖췄다.
다음 목표는 **학부모가 "우리 아이를 믿고 맡길 수 있다"고 느끼게 하는 것**이다.
원장님 일과 선생님 일이 섞여 있어서 이 작업은 별도 방에서 진행한다(원장님 결정 2026-11-08).

## 이 방이 할 일

1. 원장님·선생님께 받을 내용을 모은다(아래 '받을 것').
2. 받은 내용을 홈페이지에 올릴 **문구 초안**으로 다듬는다.
3. 완성한 문구와 사진을 홈페이지 방으로 넘긴다. 홈페이지 방이 페이지로 만들어 올린다.
   - 이 방에 저장소가 붙어 있으면 직접 올려도 된다. 그때는 저장소의 `CLAUDE.md`부터 읽는다.

## 반드시 지킬 원칙 (홈페이지 전체 규칙에서 가져옴)

- **선생님 이름은 영어 이름만**(Hwan·Sam·Eric·Kwon·Jenny). 한글 성함은 본인이 공개에 동의한 경우에만 쓴다.
- **사진은 실제 선생님·실제 학원 사진만.** 인물 스톡 사진은 실제 선생님으로 오해할 수 있어 쓰지 않는다. 사진이 오기 전까지는 지금의 모노그램을 그대로 둔다.
- **문구 원칙(2026-10-20)**:
  - 학원이 선생님 수업을 지시·점검·관리한다는 표현을 쓰지 않는다.
  - 선생님 일은 '담당 선생님이 정한 방식으로'라고 쓴다.
  - 학원이 선생님이 할 일을 학부모님께 대신 약속하지 않는다.
  - '학부모님이 받는 것'에는 학원이 하는 것만 적는다.
- **선행학습 유발 광고 금지(공교육정상화법)**: '선행', '고1 수준', '고등 과정'처럼 중학생에게 고등 과정을 앞당기는 표현은 쓰지 않는다. 중학생이 고등 모의고사를 본다는 내용도 쓰지 않는다.
- **정원은 '한 반 15명'만** 쓴다('소수 정원' 쓰지 않기). **운영 시간은 '평일 오후 3시 ~ 밤 10시'**.
- **보강:** '보강이 필요할 때는 영상 대신 선생님이 직접 만나 수업합니다'까지만 쓴다. 어떤 결석은 보강하지 않는지 같은 기준은 상황마다 달라 쓰지 않는다.
- **효과·성과 주장 금지:** 근거 없는 '성적 향상', '1등', '적중률 100%' 같은 말은 쓰지 않는다. 성적 사례는 학생·학부모 동의와 실제 숫자가 있을 때만, 이름 없이.
- **후기는 실제로 받은 것만** 쓰고 지어내지 않는다.
- **공개 저장소 주의:** 학생 이름·연락처, 계약·급여·노무 같은 내부 운영 이야기는 어떤 파일에도 쓰지 않는다.
- **교습비 표시:** 지금 '중·고등 영어 / 중등부 300,000원 · 고등부 360,000원'. 초등은 교육청 등록 전이라 쓰지 않는다.
