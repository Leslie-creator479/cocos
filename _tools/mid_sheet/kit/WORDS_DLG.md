# 대화문 어휘 더하기 — 작업 안내 (틀: 2026-10-26 중1 동아(윤정미) 2~8과. 작업 폴더에 복사해 경로를 맞춘다)

SCR = <동의어·게임 작업 폴더>
KIT = /home/claude/cocos/_tools/mid_sheet/kit (읽기만)

각 과의 동의어·반의어 페이지에는 본문 지문(이미 끝남) 뒤에 **대화문 1·대화문 2**가 붙는다. 맡은 과의 `SCR/L<n>/words.json` 끝에 **대화문 어휘 목록 두 개를 더한다**(본문 목록은 그대로 두고 맨 뒤에 `[대화문 1 어휘…]`, `[대화문 2 어휘…]` 순서로 추가).

- 형식·기준: `SCR/WORDS_SPEC.md` 전체를 그대로 따른다(지문당 6~9개, ★ 5개 이상, ko_t는 해석에 글자 그대로, span, avoid 등).
- 대화문 지문: `SCR/L<n>/passages.txt`의 `=== <n>과 대화문 1 …`, `=== <n>과 대화문 2 …` 칸(줄마다 `B:`·`G:` 말하는 사람, `[대화 1]` 이름표 줄). t·span은 대사 글자 그대로(이름표·`B:`는 포함하지 않는다).
- 품질 기준 예: `SCR/L1/words.json`의 마지막 두 목록(1과 대화문 1·2). 대화 말투라 `Perfect`·`good`처럼 짧은 대답 낱말도 고를 수 있다 — 다만 그 자리에 동의어·반의어를 넣었을 때 대화가 자연스러워야 한다(`Sounds good` → `Sounds bad`는 말이 됨).
- 대화문에 같은 낱말이 여러 번 나오면 첫 자리 기준(t가 처음 나오는 곳에 들어간다). 짧은 낱말이 다른 낱말 속에 먼저 나오면 span으로 묶는다.

## 검사 (끝 줄이 통과해야 끝)
```
cd SCR && python3 KIT/syn_lesson.py SCR <본문 학습지 작업 폴더> <n>
```
끝 줄 `보기 중복·부족 0 | 품사 섞인 보기 0 | 확인 필요: 없음 | 스크립트 오류: 없음`. 그다음 `SCR/L<n>/distractors.txt`에서 **대화문 줄(`<n>-d1`, `<n>-d2`)** 을 한 줄씩 보고, 정답이 될 만한 오답은 avoid에 넣고 다시 돌린다. 이어서 `python3 SCR/antchk.py <n>`이 있으면 돌려 반의어 넣은 문장이 이상한 곳이 없는지 본다.
다른 과 폴더·저장소는 건드리지 않고 git도 쓰지 않는다.
