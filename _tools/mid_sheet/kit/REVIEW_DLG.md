# 중등 대화문 학습지 검토 안내 (검토자용, 틀: 작업 폴더에 복사해 경로·교재를 맞춘다)

W = <대화문 작업 폴더>
학원 원장님 말씀: "학생이 풀어 보고 문제가 괜찮다고 느껴야 다른 학습지도 찾는다. 품질이 제일 중요."

맡은 과 `W/L<n>/data_d1.js`, `W/L<n>/data_d2.js`를 **학생처럼 직접 풀어 보고**(정답 보기 전에 스스로 답을 고른 뒤 비교) 검토한다. 원지문은 `W/L<n>/source.txt`. 형식 기준·문항 유형은 `W/DLG_SPEC.md`.

## 볼 것
1. **정답이 하나뿐인가** — 다른 보기도 정답이 될 수 있으면 문제. '모두 고르기'는 ⓐ~ⓔ 하나하나 맞다/틀리다가 분명한가.
2. **빈칸·표현(1·2번)**: 빈칸 앞뒤 말과 이어 읽어 자연스러운가(원어민이 실제로 그렇게 말하나). 오답이라던 것이 사실은 말이 되거나, 정답이라던 것이 어색하지 않은가.
3. **어색한 대화(5번)**: 정답 하나만 어색하고, 나머지 네 짝은 확실히 자연스러운가.
4. **대화 순서(6번)**: 다른 순서로도 말이 되지 않는가.
5. **배열(10번)**: 괄호 안 말로 다른 어순이 가능하지 않은가, N번째 답이 맞는가.
6. **사실 확인**: 내용 일치·불일치·답할 수 없는 질문·질문에 답하기·요약문이 대화 내용과 정확히 맞는가(대화에 없는 사실을 지어냈거나, '답할 수 없는' 질문이 사실은 답이 있지 않은가).
7. 해설이 정답 근거를 바르게 인용하고 틀린 보기 설명이 맞는가. 우리말 해설 문장이 자연스러운가.
8. sentences의 en·ko가 source.txt와 같은가(줄 빠짐·말하는 사람 B/G/W/M 틀림·해석 바뀜). vocab 뜻·품사가 대화 속 뜻과 맞는가.
9. order 항목의 어구 나누기가 다른 어순을 허용하지 않는가(예: 부사구 두 개를 따로 두면 순서가 바뀌어도 맞음).
10. 중1 눈높이에 맞는가, '선행'·'고등' 같은 말이 없는가.

## 고치기
- 문제가 있으면 **직접 고친다**(data_d*.js만). 정답 번호 분포는 ①~⑤ 정확히 2번씩을 지켜야 한다(바꾸면 다른 문항과 맞바꾸기).
- 고친 뒤 검사(첫 낱말 OK여야 함):
```
cd W/L<n> && for k in d1 d2; do t=$(python3 -c "import json;m=json.load(open('meta.json'));print([d['t'] for d in m['dialogs'] if d['k']=='$k'][0])"); python3 /home/claude/cocos/_tools/mid_sheet/make_mid.py data_$k.js "[코코스학원] 중1 동아(윤정미) <n>과 대화문 ${k#d} · $t" out/$k/index.html --base W/base.html >/dev/null && python3 /home/claude/cocos/_tools/mid_sheet/make_dlg.py out/$k/index.html >/dev/null && node /home/claude/cocos/_tools/mid_sheet/check_dlg.js out/$k/index.html; done
```
