### seo.py 원래 설명 (전체)
- `seo.py` (인자 없음): 검색 노출 정리. 모의고사(학력평가) 자료(`study/<연도>-<월>-g<학년>`, 같은 이름의 `syn/`·`game/`)와 수능(`suneung-…`), 홈페이지 첫 화면·자료실만 검색에 열고, 나머지(교과서·올림포스 등 부교재·학교별 자료와 그걸로 만든 동의어·단어게임, 단어장, 중등 교과서, 앞으로 생길 새 부교재 폴더)는 모두 `noindex`를 붙인다. sitemap.xml·robots.txt도 다시 만든다. 여러 번 돌려도 같고, 다른 방이 올린 페이지에 빠진 표시도 잡는다. `--check`는 고치지 않고 개수만 본다. 돌 때마다 `print_btn.py`도 함께 돌아, 학습지·동의어·반의어·단어게임에 PDF 버튼을 붙이고 안내 카드의 '학습지을' 오타를 고친다(잠긴 페이지는 건너뛴다. 새 페이지는 잠그기 전 단계라 붙는다). 출력 맨 위 'PDF 버튼: 이번에 붙인 페이지 N쪽' 줄은 새 학습지·동의어·단어게임이 있을 때만 나온다. 함께 `analytics.py`도 돌아 새 학생용 페이지에 **네이버 애널리틱스** 코드(계정 cocosedu, ID 1c961abfe2e9f50)를 붙인다('애널리틱스: 이번에 붙인 페이지 N쪽' 줄. 2026-10-18). 페이지마다 조회 수가 따로 잡혀 원장님이 어떤 자료를 많이 보는지 확인한다. 이 코드(`<!-- naver-analytics -->` 묶음)는 지우지 않는다. tools/·preview/는 세지 않는다. 또 `audio_slim.py`가 돌아 새 페이지 속 녹음과 새 발음 파일(assets/say)을 **모노 22.05kHz 24kbps**로 줄인다('녹음 줄이기(24k): … MB 줄임' 줄. 2026-10-19 선생님 결정: GitHub Pages는 공개 사이트 1GB가 한도라 돈을 내도 못 늘리고, 발음 확인용이라 이 음질로 충분하다). ffmpeg가 없으면 '건너뜀'이 나오니 `apt-get install -y ffmpeg` 후 seo.py를 다시 돌린다. 이어서 `audio_extern.py`가 돌아 새 학습지의 녹음을 페이지 밖 파일로 뺀다('녹음 빼기: 학습지 N개 · 단어 녹음 … · 문장 녹음 …' 줄. 2026-10-22): 단어 녹음(AUDIO)은 공용 발음 폴더 주소 `/assets/say/<slug>.mp3`로 바꾸고(없는 단어는 꺼내 저장), **잠그지 않는 모의고사 학습지**의 문장 녹음(SAUDIO)은 같은 폴더 `s1.mp3, s2.mp3…`로 뺀다. 교과서·부교재 문장 녹음은 지문 저작권 때문에 잠금 안(페이지 속)에 그대로 둔다. 학습지 듣기 코드는 그대로다(AUDIO[w]·SAUDIO[i]에 주소가 들어갈 뿐). 새 mp3 파일도 함께 커밋한다(`git add -A`). 마지막으로 `fix_game_pool.py`가 돌아 새 단어게임의 빈칸 보기 후보를 정리한다(고친 게 있을 때만 '단어게임 빈칸 보기 정리: N쪽' 줄). 잠긴 페이지는 건너뛰므로 반드시 잠그기 전에 seo.py를 돌린다(7번 순서). 출력을 `| head`로 자르지 말고 파일로 받는다(파이프가 끊기면 BrokenPipe).

### print_btn.py와 assets/*.js 원래 설명 (전체)
- `print_btn.py` + `assets/print-sheet.js`: 학습지 'PDF로 저장' 버튼(선생님 결정 2026-10-15). 학습지마다 맨 끝에 `<script src="…/assets/print-sheet.js"></script>` 한 줄만 붙고, 버튼과 인쇄용 화면(먼저 읽어 보세요·지문·문장별 해석·단어 정리·마인드맵·확인 문제·문장 배열·정답과 해설, 원문자는 작게·뒤에 한 칸)은 모두 이 JS 한 파일이 학습지 DATA로 만든다. PDF는 학생 기기(브라우저 인쇄 → PDF)에서 만들어지므로 저장소에 PDF 파일을 올리지 않는다. PDF 모양을 고칠 때는 `assets/print-sheet.js`만 고치면 모든 학습지에 반영된다(잠긴 페이지도 풀 필요 없음). 온라인 화면 모양은 바꾸지 않는다. 단, 이 파일은 모든 학습지가 함께 불러오므로 모든 학습지의 화면 표시를 한꺼번에 고칠 때도 여기서 한다: 요약문 빈칸 `<u>  (A)  </u>`·`<u>  (B)  </u>`를 화면·PDF 모두 `___(A)___`처럼 넓게 보이게 한다(선생님 요청 2026-10-15. DATA는 그대로 두고 표시만 바꾼다. 학습지 파일 1,000여 개를 다시 고치지 않아도 된다). 중등 학습지 요약문의 `<u>  ⓐ  </u>`·`<u>  ⓑ  </u>`도 같은 넓은 빈칸으로 보인다(2026-10-24). 빈칸 밑줄은 `cp-uline` 클래스(대화문 줄 `cp-line`과 이름이 겹치면 PDF에 줄이 그어진다). 또 지문·문항 속 ①~⑤·ⓐ~ⓔ·⑴·㉠ 같은 원숫자·원문자 바로 뒤에 영어 낱말·따옴표·밑줄 낱말이 붙으면 화면·PDF 모두 한 칸 띄운다(‘ⓐ~ⓔ가’처럼 한글 조사 앞은 띄우지 않는다), 확인 퀴즈 발문의 ‘않은·않는·없는·틀린·어색한·아닌·다른’은 바로 뒤가 ‘것·곳·질문·문장·단어·낱말·표현·부분’일 때 시험지처럼 밑줄을 긋는다(화면·PDF 모두, 선생님 요청 2026-10-24). 모두 DATA는 그대로 두고 표시만 바꾸므로 학습지를 새로 만들 때 DATA에 밑줄·띄어쓰기를 따로 넣지 않는다. 카카오톡·네이버 앱 안에서 누르면 '다른 브라우저로 열기' 안내와 바로 여는 버튼(카카오톡 `kakaotalk://web/openExternal` → 안드로이드 '다른 브라우저로 열기'·아이폰 '사파리로 열기', 안드로이드 네이버 등은 크롬 intent '크롬으로 열기')이 뜬다(2026-10-17. 앱 안 브라우저는 인쇄를 막아 PDF는 바깥 브라우저에서만 된다. 잠긴 페이지는 바깥 브라우저에서 비밀번호를 한 번 더 넣는다). 단어게임·동의어도 같다(단어게임은 PDF 창을 열 때부터 안내가 뜬다). 동의어·반의어(syn)는 `assets/print-syn.js`('지금 보는 지문 PDF'·'전체 지문 PDF' 버튼: 원지문 ★◆ 표시·해석·어휘 정리·2단계 문맥 속 고르기·3단계 어휘 추론 변형 세트·정답), 단어게임(game)은 `assets/print-game.js`('단어 목록·시험지 PDF' 버튼: 게임의 '범위 고르기'로 고른 지문(단어장은 Day, 안 고르면 전체)의 단어 목록·뜻 쓰기 시험지·영어 쓰기 시험지(순서 섞음)·정답, 고를 것을 체크)로 같은 방식이다(2026-10-15). `print_btn.py`가 페이지 종류를 알아보고 알맞은 파일을 붙인다. **단어 전체 듣기**(2026-10-22): `assets/print-sheet.js` 맨 위 몇 줄이 `assets/vocab-listen.js`를 함께 불러와, 모든 학습지의 단어 정리 위에 '단어 전체 듣기'(재생·일시정지·멈춤, 0.8배·1배, 따라 말하기, 화면 밖이면 아래 작은 막대)를 넣는다. 학습지 AUDIO 녹음을 차례로 틀고 우리말 뜻은 읽지 않으며 PDF에는 나오지 않는다. 새 학습지에도 따로 할 일 없이 들어간다. 고칠 때는 `vocab-listen.js` 한 파일만 고친다. 단어게임·단어장도 같다(2026-10-23): `assets/print-game.js` 맨 위 몇 줄이 `assets/game-listen.js`를 불러와 1단계 '단어 먼저 익히기' 화면에 '단어 전체 듣기'를 넣는다(고른 범위 단어를 화면 순서대로, assets/say 녹음). 새 단어게임에도 자동으로 들어가고, 고칠 때는 `game-listen.js` 한 파일만 고친다. 동의어·반의어 머리말의 '온라인 학습지 목차 →'·'단어게임 →' 링크(2026-10-26)와 **1단계 퀴즈 밑줄**(2026-10-27 원장님 지적)도 `assets/print-syn.js` 맨 끝 블록이 넣는다: 어휘 데이터의 바꿔 넣는 범위(t, 예 'a dear'·'allows animals to learn')를 그대로 밑줄 치면 관사·목적어까지 그어져 보기(낱말 하나)와 어긋나므로, 페이지마다 들어 있는 `ctxHTML`을 바꿔 끼워 본문 낱말(c, 표제어가 'excel at'처럼 전치사까지면 그 전치사까지)에만 긋는다. 동의어 페이지를 새로 만들 때 따로 할 일은 없다(2단계·3단계는 관사까지 함께 바꿔야 문법이 맞아 그대로).
