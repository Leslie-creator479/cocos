# 선생님 소개 요청서

학원 홈페이지(cocosedu.kr)의 선생님 카드와 선생님 소개 페이지에 넣을 내용입니다.
학부모님이 "누가 우리 아이를 가르치는지"를 보고 믿고 맡기실 수 있게 하려는 것입니다.
아래 항목을 편하게 채워 원장님께 보내 주세요. 비워 두신 칸은 홈페이지에 넣지 않습니다.

---

## 1. 기본 (필수)

- **홈페이지에 쓸 이름(영어 이름):**
- **담당:** (예: 고등부 2학년 / 중등부 중2)
- **주로 맡는 학교:** (예: 동광고·성남고)
- **가르친 햇수:** (예: 영어 강의 12년)

## 2. 사진 (선택, 넣으면 신뢰도가 크게 올라갑니다)

- 얼굴이 잘 보이는 세로 사진 1장, 가로 600px 이상
- 밝은 배경이면 좋고, 휴대폰으로 찍은 사진도 괜찮습니다
- 사진을 넣지 않으면 지금처럼 영어 이름 모노그램으로 둡니다

## 3. 한 줄 소개 (필수, 40자 안팎)

어떤 수업을 하는 선생님인지 한 문장으로 적어 주세요.
- 예: "지문 한 문장을 학생이 스스로 설명할 수 있을 때까지 확인합니다."

## 4. 수업 소개 (선택, 소개 페이지용 3~5문장)

어떤 학생을, 어떤 방식으로 가르치는지 적어 주세요. 선생님 말투 그대로 좋습니다.

## 5. 담당 반과 수업 시간 (선택)

지금 맡고 계신 반을 적어 주세요. 요일은 '월·금반', '화·목반'처럼 써 주시면 됩니다. 홈페이지에는 '반 구성과 시간은 선생님이 학원과 협의해 정합니다'라고 함께 적습니다.

| 반 이름 | 대상 (학년·학교) | 요일·시간 | 교재 |
|---|---|---|---|
| 예: 고2 UI반 | 고2 · 동광고 | 월·금반 · 오후 7시 | 예: 능률VOCA 수능필수 |
| | | | |
| | | | |

- 내신대비 시기를 학교 시험 일정에 맞춰 따로 정하시는 경우 적어 주세요. (예: 동광고는 시험 6주 전부터)
