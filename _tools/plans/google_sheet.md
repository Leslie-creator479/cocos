# 구글 시트 연결 계획 (2026-10-27 원장님과 논의, 아직 만들지 않음)

원장님이 "결과 보내기 만들어 줘", "온라인 시험 만들어 줘"처럼 말씀하시면 이 문서대로 바로 시작한다.
홈페이지(GitHub Pages)는 보여 주기만 하는 사이트라 학생이 보낸 것을 저장할 곳이 없다. 받는 곳은 **구글 시트 + Apps Script 웹 앱**으로 한다(서버·비용 없음, 원장님 구글 계정).

## 공통 원칙
- 저장소는 공개다. 학생 이름·선생님 메일·시트 주소 외의 개인정보는 저장소에 두지 않는다(선생님 메일은 원장님 시트의 표에만). Apps Script 웹 앱 주소(`…/exec`)는 페이지에서 불러야 하므로 공개 파일에 들어간다 → 마음먹으면 가짜 요청을 보낼 수 있다는 점을 원장님께 말씀드렸다.
- 학생 표시는 **학원 번호나 영어 이름**을 권한다(중1에 만 14세 미만이 있어 실명을 받으면 보호자 동의 문제가 생길 수 있음. 실명을 받으려면 원장님이 확인).
- 보내기는 **학생이 버튼을 눌러서**(몰래 자동 전송하지 않음). 학생 표시는 처음 한 번 넣으면 localStorage에 기억(try/catch).
- 알림은 메일(무료)로. 카카오톡 알림톡은 비즈니스 채널 비용·등록이 필요하다.
- 학원 규모(한 번에 몇 반)는 Apps Script로 충분. 쓰기는 LockService로 묶는다.
- 결과는 **담당 선생님에게 바로** 간다(원장님이 받아 전달하지 않게, 원장님 요청). 원장님은 전체 기록을 볼지, 설정만 맡을지 고른다(수업 이야기는 담당 선생님께 맡기는 문구 원칙과 같은 방향).

## 1. 학습지 '선생님께 결과 보내기' (학교별 시험 범위에서만)
- 원장님 생각(2026-10-27): 학교별 시험 범위 목차(`school/<학기>/<학교>-g<학년>/`)로 들어온 학생만 보내게 한다. 그 목차는 그 학교·학년 학생만 쓰므로 반을 고를 필요가 없고, 모의고사·교과서 같은 범용 자료에는 버튼을 넣지 않는다.
- 학교별 목차는 학습지를 복사한 게 아니라 원래 학습지로 링크만 건다(DATA의 `"u": "../../../study/olympos2/1-3/"`). 그래서 **목차 링크 끝에 `?s=<학교>-g<학년>`**을 붙이고(목차 DATA의 u를 고치는 짧은 스크립트), 학습지는 이 표시가 있을 때만 버튼을 보인다(sessionStorage에도 담아 학습지 안에서 옮겨 다녀도 유지). 자료실·블로그에서 바로 열면 버튼 없음.
- 화면: `assets/submit.js` 한 파일. `assets/print-sheet.js`가 challenge.js처럼 함께 불러온다(학습지마다 고칠 것 없음, 잠긴 학습지도 풀린 뒤 그대로 동작). 확인 퀴즈 결과 칸(div.done) 아래에 버튼.
- 보내는 내용: 보낸 시각, 학교·학년(s), 학생 표시, 학습지 주소·제목, 점수/문항 수, 틀린 문항 번호, **처음 푼 점수와 푼 횟수**(다시 풀어 만점 만든 뒤 보내는 것 대비), 도전 문제 점수(있으면), 걸린 시간.
- 시트: 원장님 시트에 '학교·학년 → 담당 선생님' 탭(학교·학년, 선생님 영어 이름, 선생님 메일). Apps Script `doPost`가 이 표를 보고 **선생님별 시트 파일**(프로그램이 만들어 그 선생님에게만 공유)에 한 줄 넣는다. `doGet`으로 표를 읽어 보낼 수 있게 해 두면 홈페이지를 고치지 않고 표만 바꿔 운영.
- 하루 요약 메일(시간 트리거): 선생님마다 "오늘 ○○고 2학년 5명 제출, 평균, 많이 틀린 문항".
- 지금은 한 학교·학년 학생이 여러 선생님 반에 섞일 수 있다(정규반 독해·문법 담당이 다를 수 있음). 섞이는 동안은 처음 한 번 그 학교·학년에 매핑된 선생님 두세 분 중 '내 선생님'을 고르게 한다. 앞으로 한 학교·학년을 한 선생님이 맡게 되면 이 고르기를 뺀다(원장님 말씀 2026-10-27).
- 점수 신뢰도: 숙제 여부·어려워한 곳 확인용으로 쓰고 성적으로 쓰지 않는다(정답이 페이지 안에 있고 요청을 지어낼 수 있음).

## 2. 시간 제한 온라인 시험 (예: 1시간 30문항, 끝나면 자동 제출)
- **정답은 페이지에 넣지 않고 시트에만**. 채점은 Apps Script가 한다 → 정답 미리 보기·점수 조작이 안 된다(1번과 다른 점).
- '시험 시작'을 누르면 시작 시각을 시트에 기록, 남은 시간은 그 기록으로 계산(새로고침해도 시간이 돌아가지 않음), 한 학생 한 번만 응시.
- 고를 때마다 답을 저장 → 시간이 되면 자동 제출, 창을 닫거나 휴대폰이 꺼져도 그때까지의 답으로 채점.
- 학생마다 문항·보기 순서 섞기, 시험 중 다른 화면으로 나간 횟수(visibilitychange) 기록.
- 결과: 시간이 끝나면 담당 선생님 시트로(학생별 점수, 문항별 정답률, 많이 틀린 문항), 원하면 메일.
- 한계: 집에서 보는 시험의 부정행위(책·다른 기기·도움)는 못 막는다. 학원에서 같은 시간에 보면 거의 해결. 수백 명이 같은 순간에 보는 규모는 맞지 않다.
- 구글 설문지 퀴즈는 자동 채점은 되지만 시간 제한이 없고 화면을 꾸밀 수 없어 이 용도에는 직접 만든다.

## 3. 그 밖에 이야기한 것 (원장님이 고르면)
- 학습지 **'이 문제 질문하기'**(문항 번호와 함께 담당 선생님 시트로, 질의응답 수업 준비용)·**'오류 신고'**(어느 학습지 몇 번인지 함께 와서 바로 고침). 가장 가볍고 효과가 빨라 먼저 권했다.
- 설명회 신청: 지금 **구글 폼**으로 받는 중(응답이 시트에 쌓이므로 같은 계열). 바꾸지 말고 기능만 더하기를 권했다: 새 신청 알림 메일(폼 설정), 정원이 차면 자동 마감(폼에 붙이는 짧은 스크립트), 신청자 확인 메일 자동 발송.
- 입학 테스트 예약(가능한 시간 표에서 고르기), 공지·일정을 시트에 적으면 홈페이지에 자동 반영, 단어게임 학생별 누적 오답으로 맞춤 복습, 익명 수업 설문.

## 원장님 준비 (한 번, 15분 정도)
1. 구글 시트를 새로 만든다(이름 예: 코코스 결과 받기).
2. 표 탭을 채운다(1번이면 '학교·학년 → 담당 선생님').
3. 확장 프로그램 → Apps Script → 제가 드리는 코드를 붙여 넣고 저장.
4. 배포 → 새 배포 → 웹 앱, '실행: 나', '액세스: 모든 사용자' → 권한 허용 → 나온 `…/exec` 주소를 저에게 준다.
5. (요약 메일을 쓰면) 제가 알려 드리는 함수에 시간 트리거를 하나 건다.
선생님은 구글 계정만 있으면 된다(시트는 프로그램이 만들어 공유).
