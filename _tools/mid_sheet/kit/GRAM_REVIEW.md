# 코코스 중등 문법 검토 안내 (다른 에이전트용, 2026-11-06)

당신은 한국 중학생(<학년>)용 무료 공개 영어 문법 학습지(<문법>)를 검토한다. 학생·학부모가 문제 품질로 학원을 판단하므로 정확성이 가장 중요하다. **파일을 고치지 말고 보고만 한다.**

파일: DATA `<작업 폴더>/data.js`, 만든 페이지 `<작업 폴더>/out/index.html`, 예문 출처 지문 학습지 `/home/claude/cocos/study/reading-m<학년>-<회>/<번호>/index.html`(예문 문장·번호가 원문과 같은지 확인).
DATA 키: hook(O/X, ok), rule(카드·표·팁), sentences(지문 예문), quiz(10문항, a는 0부터), fix(고쳐 쓰기, a = 정답 목록, 띄어쓰기·굽은 따옴표는 무시하고 비교, 대문자·끝 문장부호만 다르면 '거의 맞음'), write(조건 영작, 조건·단어 수 n), check, order(어구 c), review(있으면).

1. hook·quiz·fix·write·order를 **답을 가리고 먼저 직접 푼 뒤** 정답과 맞춰 본다. 답이 다르거나, 둘 이상 고를 수 있거나, 오답 보기가 실제로는 맞는 영어인 곳(미국·영국 영어 차이 포함: have gone to 경험, My family have, Did you ever ~?, 과거형 + just/already 등)을 적는다. 목표는 국내 학교 시험 관례지만, 잘 아는 교사·학생이 다른 답을 주장할 수 있으면 나쁜 문항이다.
2. 문법 설명(카드·표·팁·해설·고쳐 쓰기·영작 해설·예문 note)이 정확한지, 예외가 흔한데 '절대'처럼 쓴 과장은 없는지.
3. fix·write: 맞게 썼는데 오답이 될 답(줄임말, 같은 뜻 다른 말, 부사구 위치)을 모두 적고, 단어 수 n이 정답·조건과 맞는지, 조건만 지키면 다른 문법으로도 쓸 수 있는지(그러면 조건에 '<문법>으로 쓸 것'이 필요).
4. order: 어구 순서가 자연스럽게 하나뿐인지.
5. quiz 정답 분포(①~⑤ 2번씩).
6. 우리말: 자연스럽고 영어와 시제·뜻이 맞는지.
7. 지문 밖 사실(지명·기관 등)이 나오면 웹으로 빠르게 확인.
8. '선행'·'고1'·'고등 과정'·'한 학년 위' 같은 문구가 없는지.

보고는 한국어로 짧게: 문제마다 칸·번호, 무엇이 문제인지, 바꿀 문장(그대로 붙여 넣을 수 있게). 그다음 확인했고 괜찮은 것 몇 줄. 700단어 안팎.
