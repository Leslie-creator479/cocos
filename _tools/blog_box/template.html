__H1__

본문은 한 번에 들어갑니다. 그림만 자리마다 따로 붙이시면 됩니다.

올리는 순서

  1. 네이버 블로그에서 글쓰기를 엽니다.
  2. 제목 복사 → 제목 칸에 Ctrl + V.
  3. 글 전체 복사 → 본문 칸에 Ctrl + V. 그림 자리에 ◆ 주황색 줄이 들어갑니다.
  4. 주황색 줄을 하나씩 찾아 그 줄을 클릭하고, 아래 그림 넣기에서 같은 이름의 복사를 눌러 Ctrl + V. 그림이 들어가면 주황색 줄을 지우십시오.
  5. 발행 → 카테고리를 고르고 태그 칸에 태그 복사 → Ctrl + V.

네이버는 본문에 한꺼번에 넣은 그림을 걸러 냅니다. 그래서 그림은 한 장씩 복사해 붙이는 쪽이 확실합니다. 본문을 통째로 붙이는 것이 어려우시면 글 카드 아래 「한 칸씩 넣기」를 펴십시오 — 본문을 그림 자리에서 끊어 놓은 목록이 들어 있습니다.
