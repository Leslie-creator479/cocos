## `library/`

자료실. 맨 위 큰 구분 **고등 / 중등 / 단어장**(원장님 결정 2026-10-25), 그 아래 작은 분류: 고등 = 모의고사·수능·교과서·학교별 시험 범위, 중등 = 교과서(중등 학교별 시험 범위가 생기면 여기에 더함), 단어장은 작은 분류 없음. 안쪽 분류 이름(주소 끝 `#mock-study`·`#mid-syn`·`#voca-game` 등)은 그대로라 예전 링크도 열린다. 분류 탭 **모의고사 / 수능 / 교과서 / 학교별 시험 범위 / 중등 / 단어장**(단어장은 `game/voca-…`, 2026-10-17 추가. 중등은 교재 약칭이 `m`+학년으로 시작하는 `textbook/m2…`·`syn/m2…`·`game/m2…`, 2026-10-24 추가), 그 안에 **학습지(학교별은 '시험 범위 목차') / 동의어·반의어 / 단어게임** 작은 탭(2026-10-14 선생님 결정). 분류는 주소로 자동: 모의고사 회차 이름이면 모의고사, `textbook/`과 교과서 약칭으로 시작하는 syn·game(예 `syn/ce1min-1`)은 교과서, 나머지(학교별·부교재)는 학교별 시험 범위. 카드 데이터는 `_tools/add_library.py`로만 고친다(탭 인자는 그대로 study·textbook·school·syn·game). **중등 온라인 학습지(2026-10-24 시작)**: 중등판은 별도 스킬(cocos-passage-mid)로 만들고, 주소는 기존 폴더 안에서 교재 약칭을 `m`+학년으로 시작해 구분한다(`textbook/m2dayoon/1/2/`, `syn/m2dayoon-1`, `game/m2dayoon-1`, 잠금·검색 제외는 그대로 자동). 자료실 카드: `add_library.py textbook "1과" textbook/m2dayoon/1 4 --group "중2 동아(윤정미)"`(중등 분류로 자동). 자료실에는 중등 칸을 따로 두되 **단어장(시중 단어장 `game/voca-…`) 분류는 지금처럼 따로 유지한다**(원장님 결정 2026-10-24: 중등·고등 칸의 단어게임은 시험 범위 단어라 시중 단어장과 구분한다. 중등 단어장 4권도 단어장 분류에 그대로 둔다)
