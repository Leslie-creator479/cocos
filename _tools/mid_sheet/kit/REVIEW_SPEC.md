# 중등 학습지 확인 퀴즈 검토

맡은 과의 `SCR/L<과>/data_<k>.js` 파일들(`var DATA = {…};`)에서 **확인 퀴즈(quiz) 15문항**과 brief·map의 사실을 검토한다. SCR = <학습지 작업 폴더>

각 문항마다 확인할 것:
1. 정답(`a`, 0부터 셈)이 정말 맞는가. 지문(`sentences`)만 근거로 판단한다.
2. 정답이 하나뿐인가. 다른 보기도 맞을 수 있으면 문제다(특히 '모두 골라 짝지은 것' 조합, 답할 수 없는 질문, 빈칸, 요약문, 지칭, 다의어).
3. 어법 문항: 틀렸다고 한 곳이 정말 틀렸고, 맞다고 한 곳이 정말 맞는가(영어 문법으로 논쟁 없는가).
4. 해설(`e`)이 정답·원문과 맞는가. 원문 인용(`<i>…</i>`)이 지문 글자와 같은가.
5. 중1 수준에 맞는가(지나치게 어렵거나 애매한 표현).

고치는 법:
- 분명한 오류만 직접 고친다(보기 문구·해설·정답 번호). 정답 번호를 바꾸면 그 지문의 ①~⑤ 분포가 정확히 3번씩인지 유지해야 하므로, 정답 위치를 바꾸기보다 보기 문구를 고치는 쪽을 택한다.
- `sentences`(영어·해석), `vocab`, `order`는 고치지 않는다(녹음이 이미 만들어지고 있다). 거기서 문제를 찾으면 보고만 한다.
- 문자열은 작은따옴표로 감싸므로 안에 작은따옴표(')를 쓰지 않는다. 아포스트로피는 ’.
- 고친 뒤 파일마다 검사: `cd /home/claude/cocos && python3 _tools/mid_sheet/make_mid.py SCR/L<과>/data_<k>.js x SCR/L<과>/rv_<k>.html --base SCR/base.html && node _tools/mid_sheet/check_mid.js SCR/L<과>/rv_<k>.html && rm SCR/L<과>/rv_<k>.html` (SCR은 전체 경로로) → 첫 줄 OK.
- SCR의 다른 파일, 다른 과 폴더, L<과>/out/ 폴더는 건드리지 않는다. 저장소 파일은 고치지 않고 git 명령도 쓰지 않는다. 교재는 meta.json의 book이고 본문 원본 PDF는 SCR/L<과>/본문.pdf(필요하면 Read로 확인).

보고(짧게): 과·지문·문항 번호별로 무엇을 왜 고쳤는지 한 줄씩, 그리고 보고만 하는 문제. 문제가 없으면 없다고.
