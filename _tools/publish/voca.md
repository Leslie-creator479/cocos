# 홈페이지 게시 — 단어장 단어게임 (학원에서 쓰는 시중 단어장)

cocos-homepage-publish 스킬에서 옮긴 작업 규칙이다(2026-11-28, 스킬 크기를 줄이려고 나눔). 이 일을 할 때 읽고 규칙으로 그대로 지킨다. 'N번'은 스킬의 섹션 번호다. 공개 저장소라 학원생 비밀번호는 적지 않았다: `<비밀번호>` 자리에는 스킬에 있는 비밀번호를 넣는다.

## 9-1. 단어장 단어게임
선생님이 능률VOCA·워드마스터 같은 단어장의 **시험지 프로그램 엑셀(.xlsm)**을 올리며 "이 단어장 홈페이지에 올려줘"·"이것도 만들어줘"라고 하면 이것이다(지문으로 단어장을 만드는 cocos-wordbook과 다르다. '홈페이지'라는 말이 없고 지문을 주면 cocos-wordbook).
- **단어장 한 권 = 한 페이지** `game/voca-<약칭>`(지금 있는 단어장 목록은 저장소 `_tools/notes/game.md`). 반마다 두 과·세 과씩 범위가 달라서 Day를 하나씩 고르게 하고, 묶음 버튼은 10일 단위만. 범위 링크 `주소#4-6`(Day 04~06), `#4-5.9`.
- 틀은 단어게임과 같다(1단계 단어 익히기 + 카드 짝·60초·떨어지는 단어·철자 채우기 + 오답 다시 풀기, PDF 버튼, 녹음 발음). 예문이 없어 '지문 속 빈칸'은 뺀다. 학습지·동의어 링크 없음.
- 만드는 법은 `_tools/voca_game.py`만 쓴다(이 파일 머리말에 순서가 있다):
  1. `python3 _tools/voca_game.py extract <엑셀들 Day 순서대로> -o <스크래치>/all.json` — 'rand' 시트(C 단어·D 뜻·J '(Day NN) 단어')에서 단어·뜻·Day를 꺼내고 품사를 추정한다. 엑셀 기본 암호가 걸린 파일, Day 표시가 없는 파일(print 시트 머리말의 출제범위 Day로 순서대로 나눔)도 처리한다.
  2. **엑셀은 '순서대로' + '범위 전체'로 뽑은 것만 쓴다.** 무작위 출제 파일(rand 시트 A열 순번이 뒤섞이고 단어 수가 범위보다 적음)은 단어가 빠지니 선생님께 다시 뽑아 달라고 한다(한 번에 500개 제한이면 Day 10개씩).
  3. 품사(명·동·형·부·숙, 전치사는 부)를 꼭 검토해 고친다(뜻 보기에서 품사로 답이 보이지 않게). 많으면 서브에이전트 2~3개에 나눠 `{"Day|단어": "품사"}`로 고친 것만 받는다.
  4. meta.json: `{"title":"능률VOCA 수능필수","key":"cocos-wordgame-voca-…","chip":"… · 정규반 단어 시험","source":"단어 출처: …","group":10,"buy":{"label":"정규반 단어 교재: …","text":"교보문고에서 사기","url":"선생님이 준 구매 주소"}}` — 구매 안내는 페이지 머리말 아래 노란 칸에만 나온다. 절판 등으로 선생님이 빼라고 하면 buy를 넣지 않는다.
  5. `python3 _tools/voca_game.py build all.json meta.json game/voca-<약칭>/index.html` (제목에 '중등'·'중학'이 들어가면 중등 화면 테마가 자동으로 입혀진다. 끄려면 meta.json에 `"mid": false`) → `say_audio.py`(없는 발음 채우기, 9번. 단어장은 학습지에 없는 단어가 많아 `--make`가 필요할 때가 많다) → brand_links → 브라우저로 범위 링크·게임 점검 → `add_library.py game "<책 이름>" game/voca-<약칭> <Day 수> --group "정규반 단어장"` (**카드에 --buy 넣지 않는다**) → 7번대로 seo·lock·올리기.
- 중등·중학 단어장도 자료실에서는 그대로 단어장 칸이다. 이미 올린 단어장에 테마를 입힐 때는 unlock → `python3 _tools/mid_sheet/theme_page.py game 파일` → seo → lock.
- 시중 교재라 **학원생 비밀번호 잠금 + 검색 제외**(game/ 아래 모의고사 이름이 아니라 자동). 단어 데이터(json·엑셀)를 저장소에 평문으로 올리지 않는다(스크래치에만).
- Day를 더하거나 고칠 때: 잠긴 페이지를 복사해 unlock → `voca_game.py from-page` → 합쳐서 다시 build.
