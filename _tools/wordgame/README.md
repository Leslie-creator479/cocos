# 단어게임 스크립트 (cocos-word-game 스킬에서 옮김, 2026-11-28)

cocos-word-game 스킬의 스크립트를 글자 그대로 옮겨 둔 곳이다. 쓰는 순서와 명령은 스킬 절차에 있다. 작업 폴더(`$WORK`)에 복사해서 실행한다: `cp /home/claude/cocos/_tools/wordgame/*.py /home/claude/cocos/_tools/wordgame/*.js $WORK/`.

| 파일 | 하는 일 |
|---|---|
| prep.py | 모의고사 회차 준비(manifest·info) |
| extract.js | 학습지에서 문장·단어 꺼내기 |
| build.py | game_data.json(빈칸 보기 후보 포함) |
| mkcfg.py | 모의고사 회차 config.json |
| make_game.py | 틀의 DATA만 바꿔 단어게임 페이지 만들기 |
| test.js | 게시 전 점검(playwright) |
| mkblog.py | 모의고사 회차 blog.json·cover.json |
| make_blog.py | 블로그 원고 페이지 만들기 |
| cover.js | 대표 이미지 1080×1080 |
| add_wg.py | 블로그 수록 지문 목록에 단어게임 카드 |

## 블로그 원고 body 형식 (스킬 절차 4번에서 옮김. 규칙이라 그대로 지킨다)

- `body` (말투·순서 고정. 회차에 맞게 숫자와 범위만 바꾸고, 도입 한두 문장은 그 회차에 어울리게 쓴다):
```
["p","[대표 이미지]"]
["p","{연도}년 {월}월 {학년} 영어 모의고사 {범위} 지문 단어로 단어게임을 만들었어요."]
["b","■ 단어, 게임으로 외워 볼까요?"]
["p","단어장만 붙잡고 외우다 보면 금방 지루해지죠."]
["p","그래서 {지문수}개 지문에 나온 단어 {N}개를 다섯 가지 게임으로 만들었어요."]
(회차와 이어지는 재미있는 한 줄이 있으면 넣는다. 예: 9월 고1은 20번 지문이 '학습 게임은 적당히 재미있으면서 몰입하게'라서 "재미는 적당히 몰입은 확실하게")
["b","▶ 단어게임 바로가기"]
["link",URL,URL]
["p","휴대폰으로도 바로 할 수 있고, 로그인 없이 링크만 누르면 돼요."]
["b","■ 이렇게 해요"]
["p","· 범위 고르기: 전체, {묶음1}, {묶음2} 버튼이나 지문 번호를 눌러 공부할 범위를 골라요. 학교 시험 범위에 맞춰 고르면 돼요."]
["p","· 1단계 단어 먼저 익히기: 지문별 단어 목록에서 발음을 듣고, 뜻을 가리고 외워요."]
["p","· 2단계 게임으로 확인하기: 다섯 가지 게임 중 마음에 드는 것부터 해 보세요."]
["b","■ 게임 다섯 가지"]
["p","· 카드 짝 맞추기: 영어 카드와 뜻 카드를 뒤집어 짝 찾기"]
["p","· 60초 타임어택: 60초 동안 뜻을 몇 개나 맞힐 수 있을까?"]
["p","· 떨어지는 단어: 단어가 바닥에 닿기 전에 뜻 고르기, 목숨은 3개"]
["p","· 철자 채우기: 뜻을 보고 알파벳을 눌러 단어 완성하기"]
["p","· 지문 속 빈칸: 실제 지문 문장에서 빠진 단어 찾기. 보기가 모두 같은 품사·같은 형태라서 뜻을 알아야 풀 수 있어요."]
["br"]
["p","틀린 단어는 '오답 다시 풀기'에 모여서, 다 맞힐 때까지 다시 나와요."]
["p","게임이 끝나면 별점과 기록이 나와요. 친구와 기록 대결도 해 보세요!"]
["b","■ 더 공부하고 싶다면"]
["p","단어 목록에서 지문마다 '학습지 열기'와 '동의어·반의어 열기' 버튼이 있어요."]
["p","해석과 마인드맵, 확인 퀴즈로 지문 전체를 공부하거나, 동의어·반의어로 내신 변형 문제까지 대비할 수 있어요."]
["b","■ 범위별·지문별 바로가기"]
["p","아래 링크를 누르면 그 범위가 골라진 채로 단어게임이 열려요."]
["list"]
["p","링크는 누구에게나 자유롭게 공유해도 좋아요."]
["p","다만 내용을 복제·수정해 다른 곳에 올리거나 상업적으로 이용하는 것은 금지해요."]
```
선생님이 고친 줄 띄우기: 게임 목록 뒤 `["br"]`, 바로가기 목록 앞뒤 빈 줄(make_blog 틀이 `list` 앞뒤에 넣음). 동의어 페이지가 없으면 '동의어·반의어' 문장을 뺀다.
