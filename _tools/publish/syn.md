# 홈페이지 게시 — 동의어·반의어 (cocos-synonym-antonym)

cocos-homepage-publish 스킬에서 옮긴 작업 규칙이다(2026-11-28, 스킬 크기를 줄이려고 나눔). 이 일을 할 때 읽고 규칙으로 그대로 지킨다. 'N번'은 스킬의 섹션 번호다. 공개 저장소라 학원생 비밀번호는 적지 않았다: `<비밀번호>` 자리에는 스킬에 있는 비밀번호를 넣는다.

## 8. 동의어·반의어
- 원본 꺼내기는 3번대로 저장소에서 읽는다.
- 온라인 학습지: 완성 파일을 `wrap.py`로 `syn/<회차>/index.html`에 두고, 지문 학습지·목차 링크는 `fix_links.py`로 상대 경로. 자료실 `add_library.py syn "2026년 10월 고1" syn/2026-10-g1 22`.
- 블로그 원고 페이지(정식 모의고사만): `blog.json`의 `title` 끝에 ` | 성남 코코스영어학원`을 붙여 만든다(6번). `tools/syn-blog/<회차>/index.html`에 `wrap.py --noindex`로 두고 `fix_links.py --absolute`(블로그에 붙일 링크라 전체 주소). 넣은 뒤 `build_tools_index.py`. 학교별·교과서 동의어는 블로그 원고를 만들지 않는다.
- 학교별 동의어·반의어 학습지는 `syn/<연도>-<학기>-<mid·final>-<학교>-g<학년>`(예 `syn/2026-2-mid-dongkwang-g1`), 자료실은 `add_library.py syn "동광고 1학년" syn/2026-2-mid-dongkwang-g1 28 --group "2026년 2학기 중간고사 · 학교별"`(기말은 `"2026년 2학기 기말고사 · 학교별"`). 교과서·부교재 지문이 섞인 범위만 잠기고(lock.mjs), 모의고사 지문만 묶은 범위는 공개다(`public_school.py`가 자동 판단). 만드는 순서는 cocos-school-mock-range 스킬.
- **교과서 동의어·반의어는 과마다 따로 만든다**(단어게임도 같다). '4~6과'처럼 여러 과를 한 번에 부탁받아도 `syn/neo2-4`, `syn/neo2-5`, `syn/neo2-6` 세 페이지로 나누고 자료실 카드도 과마다 `add_library.py syn "영어II NE능률(오선영) 4과" syn/neo2-4 <지문 수> --group "영어II NE능률(오선영)"`. 교과서 지문 목록(`tools/textbook-list/`)에도 과마다 한 줄(그 과 교과서 줄 바로 아래).
- 예전 블로그 원고는 모두 홈페이지(`tools/…`)로 옮겨졌다. 고칠 때는 저장소 파일을 고친다.
- 자료실 개수 맞추기: 모의고사·교과서 탭의 학습지·동의어·단어게임 카드 수가 같아야 한다. 선생님이 '숫자가 안 맞는다'고 하면 세 탭의 카드 경로를 비교해 빠진 회차·과를 찾아 만든다.
