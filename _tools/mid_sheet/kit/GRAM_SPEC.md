# 코코스 중등 문법 DATA 쓰기 안내 (2026-11-06, 견본 study/grammar-m2-01)

`var DATA = { … };` 한 덩어리. 견본 DATA(작업 폴더 sample.js)와 키·분량·말투를 그대로 맞춘다. 화면 문구는 학생에게 말하듯 '~해요'.

| 키 | 쓰는 법 |
|---|---|
| chips | `['코코스 중등 문법 · <학년>', '<회>회 · <문법> · 독해 <회>회 <번호>번 문장으로']` (둘째 칸의 가운데가 문법 이름: 독해 지문의 '문법 학습지 →' 안내가 이 칸을 읽는다) |
| h1 | `<문법>: <질문형 제목>` |
| enTitle | 영어 문법 이름 · 꼴 (예 `Present Perfect — have / has + p.p.`) |
| gist | 2~3문장. 지문 속 맞는 문장 → 바꾸면 틀리는 문장 → 이 학습지에서 할 것 |
| footer | `예문: 코코스 중등 독해 <학년> <회>회 <번호>번(코코스학원 오리지널 지문) · 핵심 문법 <문법>` |
| hook | intro + items 5개(`en`, `ok`, 틀린 것은 `fix`(고친 문장, 바뀐 곳 `<b>`), `e`) + after(한 줄 결론). O 2개·X 3개 안팎, 지문 문장 2개 이상, 자주 틀리는 문장 3개 |
| rule.cards | `key: true` 카드 2개(꼴, 느낌) + 쓰임 카드(①②③…, `w` = 함께 쓰는 말 칩, `ex`·`ko`, 지문 문장이면 ko 끝에 '(…지문/일기 N번)'). 칩(w)에는 '함께 쓰는 말'만, 동사 목록 같은 것은 `t`에 |
| rule.table | 헷갈리는 짝(예 과거형 vs 현재완료, who vs which, 동명사 vs to부정사) 3줄 안팎. 한쪽 전용처럼 보이는데 실제로 둘 다 되는 말은 '둘 다 되는 말' 줄로 |
| rule.tips | 3개(시험 함정·형태·학교 시험 관례는 '학교 시험에서는'을 붙여) |
| sentences | 4~6개, 지문 문장 그대로. `en`(녹음용 평문, 한 줄에 `{ en: '…', show: '…', ko: '…', tag: '…', past: true?, note: '…' },`, 블록 끝은 줄 첫머리 `  ],`), `show`(핵심 부분 `<u>`), `tag`(쓰임 · 지문 N번), 대비 문장은 `past: true`(회색 꼬리표) |
| quiz | 10문항: 기본 3(빈칸·꼴, 짝 고르기, 우리말 → 영어) · 표준 4(틀린 문장 고르기, 같은 쓰임, 대화 빈칸, (A)(B) 짝) · 심화 3(옳은 문장 개수, 짧은 글 밑줄 ⓐ~ⓔ 틀린 것, 두 문장 → 한 문장). `type`·`lv`·`p`·`q`·`en`(영어 보기일 때만)·`o` 5개·`a`(0부터)·`h`(힌트, 있으면)·`e`. **정답 ①~⑤ 2번씩**. 오답 보기는 분명히 틀린 것만(미국·영국 영어에서 맞는 표현은 보기로 쓰지 않음) |
| fix | 5개: `w`(틀린 문장, 밑줄 없이), `ko`, `a`(정답 목록: 줄임말·부사구 앞으로 보낸 꼴 등 맞는 다른 답을 모두), `h`, `e` |
| write | 3개: `ko`, `cond`(첫 조건 '<문법>으로 쓸 것', 꼭 쓸 말, 단어 수, 줄임말 없이), `n`(단어 수 = 정답 단어 수), `a`(조건을 지키는 다른 답도 모두), `h`, `e` |
| check | 서술형 감점 체크 6줄(그 문법의 형태 점검 3~4줄 + 조건·대문자·마침표·철자) |
| order | 4개: `ko`(영어와 시제·뜻이 맞게), `c`(어구 3~4개), `src`(지문 문장이면 '지문 N번 문장에서'), `e`(한 줄 요점). 부사구를 앞에 둬도 되는 문장은 피하거나 그 어구를 맨 끝에 둔다(안내에 '기간·때는 끝에') |
| review | (2편째부터, 선택) 지난 편 문법 복습 2~3문항(quiz 꼴). 같은 학년 지난 편이 있으면 넣는다 |
| links | 첫 줄 짝 지문 `{ href: '../reading-m<학년>-<회>/<번호>/', t: '독해 <회>회 <번호>번 · <지문 제목>', d: … }`, 둘째 회차 목차, 셋째 자료실 `../../library/` |

- `<title>`: `[코코스학원] <학년> 영어 문법 <회>회 · <문법> · <질문형 제목 한 줄>`.
- 해석(ko)은 지문 학습지의 해석을 그대로 쓴다. 새 예문은 짧고 중학 기본 어휘로.
- 선행 광고 금지 문구('선행'·'고1'·'고등 과정'·'한 학년 위')를 쓰지 않는다. 그 학년 문법만 다룬다.
- 홑따옴표 안의 아포스트로피는 ’(굽은 따옴표)로 쓴다(JS 문자열이 깨지지 않게, 채점은 같은 글자로 본다).
