블로그 수록 지문 목록

줄마다 해당 지문의 온라인 학습지 링크가 걸려 있어요. 복사해서 네이버 블로그 글에 붙여 넣으면 학생이 번호를 눌러 바로 공부를 시작할 수 있어요.

  1. 아래에서 ‘링크 포함 복사’를 눌러요.
  2. 네이버 블로그 글쓰기에서 ‘■ 수록 지문’ 자리에 붙여 넣어요.
  3. 한 줄을 눌러 링크가 걸렸는지 확인하고 발행해요.

작업 현황

회차별로 만든 자료예요. 칸을 누르면 그 회차로 이동해요. 학습지 = 온라인 학습지, 동의어 = 동의어·반의어, 게임 = 단어게임. 빈칸(—)은 아직 안 만든 회차예요.

붙여 넣었는데 링크가 사라졌다면, 아래 미리보기 목록을 마우스로 드래그해 선택한 뒤 Ctrl+C(맥은 ⌘+C)로 복사해 붙여 넣어 보세요.
