## 무엇을 만드나
코코스학원 고등 온라인 학습지(모의고사 지문)마다 이미 **기본 확인 퀴즈 15문항**이 있다. 원장님 평가: 기본 퀴즈는 원문 낱말이 그대로 답이고 오답이 동떨어져 **쉽다**. 그래서 상위권·시험 직전용 **도전 문제 10문항**을 따로 붙인다. 원장님 요청 그대로:
- **①~⑤ 고르기가 까다로워야 한다**(오답이 그럴듯해야 한다).
- **지문 변형이나 단어 변형이 있어야** 쉽지 않다.
- 10문항이면 충분하다. 너무 어려워 포기하게 만들지는 않는다(억지·논쟁거리 문제 금지, 근거가 글 안에 분명해야 한다).
목표 난이도: 학원 고1·고2 상위권 정답률 50~70%. 내신 고난도 변형 문제 수준.

## 먼저 할 일
`node REPO/_tools/challenge/dump.js REPO/study/<회차>/<번호>/index.html` 로 지문(문장·해석)과 **기본 확인 퀴즈**를 본다. 도전 문제는 기본 퀴즈와 같은 발췌·같은 정답 자리·같은 보기를 다시 쓰지 않는다(같은 유형 이름이어도 묻는 자리와 방식이 달라야 한다).

## 10문항 구성 (이 순서, type 표기 그대로)
| # | type | 만드는 법 |
|---|---|---|
| 1 | `제목 · 고난도` (편지·안내문이면 `목적 · 고난도`, 심경 지문이면 `심경 변화 · 고난도`) | 정답은 원문 낱말을 거의 쓰지 않은 바꿔 쓴 표현(비유·의문형 제목도 좋다). 오답 4개는 모두 그럴듯하게: ⓐ 글의 소재·예시만 맞는 것 ⓑ 범위가 너무 넓은/좁은 것 ⓒ 원인·결과를 뒤집은 것 ⓓ 원문 핵심어를 그대로 썼지만 논지가 다른 것. 영어 보기(`en: true`) |
| 2 | `빈칸 · 변형` | 글의 핵심 주장·결론 자리 어구를 빈칸으로. **정답은 원문 어구가 아니라 같은 뜻을 다른 말로 바꾼 표현**. 오답 중 1개 이상은 원문 낱말을 그대로 쓰되 뜻이 틀린 함정. 기본 퀴즈의 빈칸 자리와 겹치면 다른 문장을 고른다. q에는 빈칸을 넣은 지문(필요한 부분, 원문 그대로 + 빈칸 `______`) |
| 3 | `요약문 · 변형` | 요약문 한 문장(영어)의 (A)(B) 정답이 **모두 원문에 없는 낱말**(동의어·상위어). 오답은 원문에 나온 낱말로 만든 짝을 섞어 함정을 만든다. 빈칸은 `<u>  (A)  </u>`, 보기 `isolated — ripple` 꼴 |
| 4 | `어휘 · 변형` | 원문 일부를 **동의어로 바꿔 쓴 변형 지문**을 q에 싣고 밑줄 ①~⑤ 다섯 낱말 중 **문맥상 쓰임이 적절하지 않은 것** 하나(반의어·엉뚱한 말로 바꾼 자리). 나머지 넷은 바꾼 동의어라 낯설지만 맞는 말. 기본 퀴즈의 어휘 밑줄 자리와 겹치지 않게 |
| 5 | `어법 · 개수` | 지문 일부에 밑줄 ⓐ~ⓔ 5곳, **어법상 틀린 것의 개수**. 보기 `1개`·`2개`·`3개`·`4개`·`5개`, 정답은 1~3개. 동사/준동사, 관계사 what/that/which, 수 일치, 능동/수동, 병렬, 형용사/부사, 대명사 수 등 내신 단골. 틀린 자리는 확실히 틀리고, 맞는 자리는 확실히 맞아야 한다(논쟁 금지). 기본 퀴즈 어법 자리와 다른 곳 |
| 6 | `무관한 문장 · 변형` | 원문 흐름 4문장 + **직접 지어낸 그럴듯한 문장 1개**(같은 소재·같은 낱말을 쓰지만 논지에서 벗어난 문장)를 ①~⑤로 표시해 q에 싣는다. 지어낸 문장이 정답. 흐름이 자연스럽게 이어지도록 원문 문장 순서는 그대로 |
| 7 | `순서 · 변형` 또는 `문장 삽입 · 변형` | 기본 퀴즈와 다른 자리로 자르고, 원문의 연결어·지시어 단서를 일부 **바꿔 써서**(예: However → Even so, this → such a view) 단서를 줄인다. 정답이 하나로 정해져야 한다. 순서 보기는 기본처럼 `(A) — (C) — (B)` 꼴 |
| 8 | `함축 의미 · 변형` | 원문의 한 표현(또는 원문 뜻을 비유로 바꿔 쓴 표현)에 밑줄, **그 의미로 가장 적절한 것**. 오답은 글의 다른 부분 내용·문자 그대로의 뜻·지나친 확대 해석. 영어 보기 권장 |
| 9 | `내용 일치 · 개수` | (a)~(e) 다섯 진술을 원문과 다른 말로 바꿔 쓴 한국어 또는 영어 문장으로, **글의 내용과 일치하는 것의 개수**. 보기 `1개`~`5개`, 정답 2~4개. 틀린 진술은 숫자·주체·정도·인과를 살짝 바꾼 것 |
| 10 | `추론 · 고난도` | 다섯 학생의 말(`민준: …`) 중 **글을 바르게 이해한 사람**, 또는 영어 질문(Q: Why/What …?)에 대한 가장 적절한 답. 정답은 글에서 한 단계 추론해야 나오고, 오답은 그럴듯하지만 글에 근거가 없거나 반대 |

- 지문 성격상 어떤 유형이 정말 안 되면(예: 29·30번처럼 어법·어휘가 기본 문제인 지문, 26번 인물 소개, 매우 짧은 지문) 같은 표의 다른 유형(빈칸·변형 하나 더, 요약문, 내용 일치 개수 등)으로 바꾸되 10문항을 채운다. 대체했으면 보고에 적는다.
- **변형 지문은 원문 뜻을 바꾸지 않는다**(문항이 노리는 한 자리만 다르다). 지어낸 문장은 6번 무관한 문장 하나뿐이다.
- 지문이 긴 장문(41-42, 43-45)은 필요한 부분만 발췌한다.

## 형식 (파일: CH/<회차>/<번호>.js, 예 CH/2026-10-g2/34.js)
```js
var CHALLENGE = [
  { type: '제목 · 고난도', p: '윗글의 제목으로 가장 적절한 것은?', en: true,
    o: ['…', '…', '…', '…', '…'], a: 2,
    h: '…(힌트, 선택)', e: '정답 근거를 원문 <i>…</i>로 인용하고, 함정 오답 2~3개가 왜 틀렸는지 짧게.' },
  …10개
];
```
- 키: type, p(발문), q(발췌·지문, 선택), o(보기 5개), a(정답 0~4), e(해설), h(힌트, 10문항 중 3~4개만), en(영어 보기면 true).
- **정답 번호는 ①~⑤가 정확히 2번씩.** 개수형(5·9번)은 보기 순서가 1개~5개로 고정이니 정답 개수에 맞춰 다른 문항으로 분포를 맞춘다.
- 문자열은 작은따옴표로 감싸므로 안에 작은따옴표(')를 쓰지 않는다. 아포스트로피는 ’. 밑줄은 `<u>…</u>`, 원문자 밑줄은 `①<u>word</u>` 또는 `ⓐ<u>word</u>`. 문장 번호 표시는 `①` 뒤에 띄어 쓴다.
- 해설 `e`: 원문 근거를 `<i>원문 그대로</i>`로 인용(인용은 지문 글자와 똑같이). 변형 문항은 "원문에서는 ○○였다"를 밝힌다. 개수형은 틀린 자리마다 왜 틀렸는지.
- 발문 예: `다음 글의 밑줄 친 부분 중, 문맥상 낱말의 쓰임이 적절하지 않은 것은?`, `밑줄 친 ⓐ~ⓔ 중 어법상 틀린 것의 개수는?`, `윗글의 내용과 일치하는 것의 개수는?`, `다음 글에서 전체 흐름과 관계 없는 문장은?`, `윗글을 바르게 이해한 사람은?`

## 스스로 검사 (모두 통과해야 끝)
1. 복사본에 넣어 형식 검사:
```
mkdir -p CH/test && cp REPO/study/<회차>/<번호>/index.html CH/test/<회차>-<번호>.html && python3 REPO/_tools/add_challenge.py CH/test/<회차>-<번호>.html CH/<회차>/<번호>.js
```
   첫 낱말이 `OK`, `도전 10문항 · 정답 분포 [2, 2, 2, 2, 2]`여야 한다.
2. 문항마다 **직접 다시 풀어 본다**: 정답이 하나뿐인지, 오답 가운데 정답으로도 볼 수 있는 것이 없는지, 개수형의 개수가 맞는지, 변형 지문의 나머지 부분이 원문과 뜻이 같은지, 해설 인용이 지문 글자와 같은지.
3. 기본 확인 퀴즈와 같은 문항이 없는지.
