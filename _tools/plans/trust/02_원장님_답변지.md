# 원장님 답변지

실제로 하시는 대로만 짧게 적어 주시면 됩니다. 상황마다 다르면 "상담으로 정한다"고 적으셔도 충분합니다.
홈페이지 문구는 이 답을 바탕으로 따로 다듬어 다시 보여 드립니다.

---

## 1부. '이럴 땐 어떻게 하나요?' 문답

1. **성적이 떨어졌을 때** 학원은 무엇을 하나요? (예: 누가 연락하는지, 상담 시기, 수업·자료 조정)
2. **반이 아이에게 맞지 않을 때** 반 이동은 어떻게 정하나요? (예: 레벨 테스트, 시기, 누가 결정하는지)
3. **결석했을 때**는 어떻게 하나요? (홈페이지 기준 문구: '보강이 필요할 때는 영상 대신 선생님이 직접 만나 수업합니다'. 보강 기준은 쓰지 않습니다)
4. **선생님께 직접 말씀드리기 어려운 일**이 있으면 학부모님은 어디로 연락하면 되나요? (예: 원장님 직통, 네이버 톡톡)
5. **과제를 안 해 오거나 학원에 안 나오는 일이 반복될 때**는 어떻게 하나요?
6. **학원을 그만두거나 쉬고 싶을 때** 절차는? (교습비 반환은 학원법 기준을 따른다고만 써도 됩니다)
7. 그 밖에 학부모님이 자주 물으시는 것이 있으면 적어 주세요.

## 2부. '학부모님이 받는 것' 확인

지금 홈페이지에 흩어져 있는 약속들입니다. 맞는지, 빠진 것은 없는지 표시해 주세요.

| 언제 | 무엇을 | 맞음 / 고침 |
|---|---|---|
| 입학 상담 | 입학 테스트 → 결과 상담 → 레벨별 반 편성 | |
| 첫 수업 전 | 오리엔테이션: 교재·진도·과제 안내, 담당 선생님과 만남 | |
| 입학 2주 후 | 학원이 학부모님께 안부 연락(적응·바라시는 점을 여쭘) | |
| 시험 5주 전 | 고등부 학교별 내신대비반(4주 진도 + 1주 최종) | |
| 학교 범위 공지 뒤 | 범위 지문 온라인 학습지·동의어·단어게임 | |
| 모의고사 8회쯤마다 | 분석 리포트(2~3개월에 한 번, 요청하면 수시, 평균·등수 없음) | |
| 시험 뒤 | 학교별 시험 분석(홈페이지 학교별 내신 가이드) | |
| 빠진 것 | (예: 출결 알림, 정기 상담 주기 등) | |

※ 선생님마다 다른 것(상담 방식 등)은 여기에 넣지 않고 선생님 소개에 '담당 선생님이 정한 방식'으로 둡니다.

- [ ] 교실(수업 전 빈 교실, 칠판·책상이 보이게)
