  2. 문법은 새 문장으로 연습동명사·감각동사·비교급이 교과서 밖 문장으로 여러 문항 나왔어요. 교과서 예문만 외우면 부족해요.
  3. '모두 고르기' 대비보기 5~6개를 모두 판단하는 조합형이 4문항 18점이었어요. 보기마다 O/X와 이유를 적는 습관이 필요해요.
  4. 본문 어법 포인트가 그대로어법 문항과 서술형 1문항이 코코스 내용정리 자료의 '어법 점검'에서 고쳐 본 자리였어요.
  5. 서술형 조건 체크단어 수, 시제, 축약형 금지 조건에 번호를 매겨 확인하는 연습을 해요.

06 — How to Prepare

성일중 영어, 이렇게 준비하세요

  1. 교과서 원문을 그대로 외우기두 학년 모두 지문 58~66점이 교과서 대화문·본문 원문이었어요. 선택지에서 바뀐 한 단어를 찾으려면 원문이 정확해야 해요.
  2. T/F 문장과 어법 점검 끝까지내용정리 자료의 T/F 문장과 '어법 점검' 고치기 지점이 선택지와 서술형에 그대로 나왔어요.
  3. 문법은 교과서 밖 새 문장으로문법 문항은 처음 보는 문장이었어요. 문법마다 맞는 문장·틀린 문장을 직접 만들어 봐요.
  4. 보기 여러 개를 하나씩 판단하기'모두 고르기', '옳은 것 개수' 문항은 하나만 잘못 봐도 틀려요. 보기마다 O/X와 이유를 적어요.
  5. 서술형은 조건부터 확인단어 수, 시제, 축약형 금지, 관계대명사 포함 같은 조건에 번호를 매기고 답을 쓴 뒤 다시 확인해요.
