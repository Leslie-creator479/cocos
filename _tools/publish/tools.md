# 홈페이지 게시 — 그 밖의 도구와 자료실 화면

cocos-homepage-publish 스킬에서 옮긴 작업 규칙이다(2026-11-28, 스킬 크기를 줄이려고 나눔). 이 일을 할 때 읽고 규칙으로 그대로 지킨다. 'N번'은 스킬의 섹션 번호다. 공개 저장소라 학원생 비밀번호는 적지 않았다: `<비밀번호>` 자리에는 스킬에 있는 비밀번호를 넣는다.

## 도구 (스킬 2번에서 옮김)
- `print_btn.py` + `assets/print-sheet.js`: 학습지 'PDF로 저장' 버튼. 학습지마다 맨 끝에 `<script src="…/assets/print-sheet.js"></script>` 한 줄만 붙고, 버튼과 인쇄용 화면은 모두 이 JS 한 파일이 학습지 DATA로 만든다. PDF는 학생 기기(브라우저 인쇄 → PDF)에서 만들어지므로 저장소에 PDF 파일을 올리지 않는다. PDF 모양을 고칠 때는 `assets/print-sheet.js`만 고치면 모든 학습지에 반영된다(잠긴 페이지도 풀 필요 없음). 온라인 화면 모양은 바꾸지 않는다. 단, 이 파일은 모든 학습지가 함께 불러오므로 모든 학습지의 화면 표시를 한꺼번에 고칠 때도 여기서 한다(요약문 빈칸 넓게, 원숫자·원문자 뒤 띄어쓰기, 확인 퀴즈 발문 밑줄 등). 빈칸 밑줄은 `cp-uline` 클래스(대화문 줄 `cp-line`과 이름이 겹치면 PDF에 줄이 그어진다). 모두 DATA는 그대로 두고 표시만 바꾸므로 학습지를 새로 만들 때 DATA에 밑줄·띄어쓰기를 따로 넣지 않는다. 카카오톡·네이버 앱 안에서 누르면 '다른 브라우저로 열기' 안내와 바로 여는 버튼이 뜬다(앱 안 브라우저는 인쇄를 막아 PDF는 바깥 브라우저에서만 된다. 잠긴 페이지는 바깥 브라우저에서 비밀번호를 한 번 더 넣는다). 단어게임·동의어도 같다(단어게임은 PDF 창을 열 때부터 안내가 뜬다). 동의어·반의어(syn)는 `assets/print-syn.js`, 단어게임(game)은 `assets/print-game.js`로 같은 방식이다. `print_btn.py`가 페이지 종류를 알아보고 알맞은 파일을 붙인다. **단어 전체 듣기**: `assets/print-sheet.js` 맨 위 몇 줄이 `assets/vocab-listen.js`를 함께 불러와 모든 학습지의 단어 정리 위에 넣는다. 새 학습지에도 따로 할 일 없이 들어간다. 고칠 때는 `vocab-listen.js` 한 파일만 고친다. 단어게임·단어장도 같다: `assets/print-game.js` 맨 위 몇 줄이 `assets/game-listen.js`를 불러와 1단계 '단어 먼저 익히기' 화면에 넣는다. 새 단어게임에도 자동으로 들어가고, 고칠 때는 `game-listen.js` 한 파일만 고친다. 동의어·반의어 머리말의 '온라인 학습지 목차 →'·'단어게임 →' 링크와 **1단계 퀴즈 밑줄**도 `assets/print-syn.js` 맨 끝 블록이 넣는다(페이지마다 들어 있는 `ctxHTML`을 바꿔 끼워 본문 낱말에만 긋는다). 동의어 페이지를 새로 만들 때 따로 할 일은 없다(2단계·3단계는 관사까지 함께 바꿔야 문법이 맞아 그대로).
- `public_school.py`: school/ 목차를 읽어 지문 링크가 모두 모의고사·수능 학습지인 범위를 `_tools/public_school.json`(공개 이름 목록, 예 `2026-2-final-seongnam-girls-g2`)에 쓴다. **seo.py가 돌 때 맨 먼저 불러** 그 목차·syn·game을 검색에 열고, lock.mjs가 이 목록을 읽어 그 syn·game을 잠그지 않는다. 그래서 새 학교별 범위도 따로 할 일 없이 seo → lock 순서만 지키면 된다. `--check`는 보기만.
- `unlock_public.mjs`: 이미 잠긴 페이지가 공개로 바뀌었을 때 쓴다. `node _tools/lock.mjs status`가 '공개 자료인데 잠긴 쪽 N쪽'을 알려 주면 `COCOS_LOCK_PW=<비밀번호> node _tools/lock.mjs unlock <파일…>` → `node _tools/unlock_public.mjs <파일…>`(잠글 때 바뀐 '학원생 전용·저작권' 안내를 공개 모의고사 페이지의 '친구에게 공유해 주세요'·'자유롭게 공유해도 좋아요' 문구로 되돌림) → seo.py → lock.
- `audio_extern.py`: 학습지 녹음을 페이지 밖 파일로 빼기(seo.py가 자동으로 부른다. `--check`는 개수만). 이미 잠긴 페이지를 바꾸려면 unlock → 이 도구 → lock.
- `mid_sheet/`: 중등 학습지 도구(make_mid.py·make_toc_mid.py·build_lesson.py·check_mid.js·build_audio.py·build_saudio.py·mid_theme.css)와 중등 동의어·반의어·단어게임 화면 도구 `theme_page.py syn|game 파일`(mid_common.css + mid_syn.css/mid_game.css). 쓰는 법은 cocos-passage-mid.
- `fix_game_pool.py`: 단어게임 '지문 속 빈칸' 보기 후보 정리. **seo.py가 돌 때 함께 돌아** 새 단어게임은 잠그기 전에 자동으로 정리된다('단어게임 빈칸 보기 정리: N쪽' 줄). 잠긴 게임을 검사하려면 복사본을 unlock해 `python3 _tools/fix_game_pool.py --check 파일`.

## 9-2. 자료실 화면
- 맨 위 큰 구분은 **고등 / 중등 / 단어장**. 고등을 누르면 아래 줄에 모의고사 · 수능 · 교과서 · 학교별 시험 범위, 중등을 누르면 교과서(중등 학교별 시험 범위가 생기면 `library/index.html`의 `LV.mid`에 분류를 더한다), 단어장은 아래 줄 없이 바로 목록. 그 밑이 학습지 / 동의어·반의어 / 단어게임 탭. 안쪽 분류 이름(mock·suneung·textbook·school·mid·voca)과 주소 끝 `#mid-syn`·`#voca-game` 같은 링크는 그대로라 예전 링크도 그 칸으로 열린다. 카드는 지금처럼 `add_library.py`로 넣으면 주소 규칙(1번)대로 칸이 정해진다.
- 안쪽 분류는 모의고사 / **수능**(`suneung-…`) / 교과서 / 학교별 시험 범위 / **중등**(교재 약칭 `m`+학년) / **단어장**(game/voca-…). 단어장 탭은 단어게임만 보이고 카드에 'Day N개'로 나온다. 중등 탭은 '1과 · N개 본문'으로 보이고, 시중 단어장(중등 단어장 포함)은 중등이 아니라 단어장 분류에 그대로 둔다(원장님 결정: 중등·고등 칸 단어게임은 시험 범위 단어라 시중 단어장과 구분).
- 교과서 탭은 학습지·동의어·단어게임 카드가 모두 '1과 · N개 본문'으로 같게 보인다(카드 제목 앞의 교재 이름을 화면에서 자동으로 뗀다). 카드 데이터는 그대로 `add_library.py`로 넣으면 된다.
