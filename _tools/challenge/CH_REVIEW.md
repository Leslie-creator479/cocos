당신은 다른 사람이 만든 고등 모의고사 지문의 **도전 문제 10문항**(CH/<회차>/<번호>.js, `var CHALLENGE = [...]`)을 검토하고 고친다. 만든 기준은 REPO/_tools/challenge/CH_SPEC.md에 있다(읽는다). 지문과 기본 퀴즈는 `node REPO/_tools/challenge/dump.js REPO/study/<회차>/<번호>/index.html`.

## 할 일
1. **모든 문항을 학생처럼 직접 푼다**(정답을 먼저 보지 말고). 그다음 정답과 비교한다.
2. 고칠 것(발견하면 바로 고친다):
   - 정답이 틀렸거나, 정답으로 볼 수 있는 보기가 둘 이상인 문항
   - 개수형(어법·개수, 내용 일치·개수)의 개수가 틀린 것, '맞는 자리'가 사실은 논쟁거리인 것(교과서·수능 기준으로 확실히 맞거나 틀려야 한다)
   - 변형 지문이 문항이 노리는 자리 말고도 원문과 뜻이 달라진 것, 무관한 문장(6번)이 실제로는 흐름에 맞거나 다른 원문 문장이 더 어색한 것
   - 순서·삽입 문항의 답이 하나로 정해지지 않는 것
   - 해설 `<i>…</i>` 인용이 지문 글자와 다른 것(변형 지문의 낱말을 원문인 것처럼 인용한 것 포함)
   - 너무 쉬운 문항(오답이 동떨어져 바로 지워지는 것) → 오답을 더 그럴듯하게
   - 억지 문항(근거가 글에 없고 해석에 따라 갈리는 것) → 근거가 분명하게
   - 기본 확인 퀴즈와 사실상 같은 문항
3. 고친 뒤에도 **정답 번호는 ①~⑤ 정확히 2번씩**. 형식 검사:
```
mkdir -p CH/test && cp REPO/study/<회차>/<번호>/index.html CH/test/rv-<회차>-<번호>.html && python3 REPO/_tools/add_challenge.py CH/test/rv-<회차>-<번호>.html CH/<회차>/<번호>.js
```
   첫 낱말이 `OK`여야 한다.
4. 문자열 규칙: 작은따옴표로 감싸므로 안에 '(곧은 작은따옴표) 금지, 아포스트로피는 ’.
